# User Management Lab

## Objectives

Learn basic user administration tasks commonly performed by IT Support teams.

## Tasks Completed

- Created local users using PowerShell
- Created local groups
- Added users to groups
- Reset user passwords
- Disabled and enabled accounts

## PowerShell Commands Used

Get-LocalUser

New-LocalUser

New-LocalGroup

Add-LocalGroupMember

Disable-LocalUser

Enable-LocalUser

Set-LocalUser

## Skills Developed

- User administration
- Permission management
- Password management
- Account lifecycle management
