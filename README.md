# IT Support Home Lab

## Overview

Built a Windows 11 ARM virtual machine using UTM on Apple Silicon to develop practical IT Support skills.

## Tasks Completed

### User Administration

- Created local user accounts
- Created security groups
- Assigned users to groups
- Reset passwords
- Disabled and enabled user accounts

### Networking

- Used ipconfig to view network configuration
- Tested connectivity with ping
- Performed DNS lookups using nslookup
- Traced network paths using tracert

### Windows Administration

- Explored Event Viewer logs
- Reviewed hardware through Device Manager

## Tools Used

- UTM
- Windows 11 ARM
- PowerShell
- Command Prompt
